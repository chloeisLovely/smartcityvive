# 실시간 워드클라우드 수집 페이지

고양 스마트시티즌 · 「제미나이·노트북LM으로 끝내는 AI 업무 자동화」 1회차 도입 활동용.

| 파일 | 역할 |
|---|---|
| `index.html` | 교육생 화면. 버튼을 고르고 직접 적어서 보냅니다 |
| `teacher.html` | 강사 화면. 모인 답이 워드클라우드로 보입니다 |
| `config.js` | 수집 주소 한 줄. **여기만 고치면 됩니다** |
| `Code.gs` | 구글 시트에 붙여넣을 백엔드 코드 |

---

## 1단계 · 구글 시트로 수집함 만들기

1. 구글 드라이브에서 **새 스프레드시트**를 하나 만듭니다. 이름은 `워드클라우드 응답` 정도로 붙입니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 편집기에 원래 있던 `function myFunction() {}` 를 **모두 지우고**, `Code.gs` 파일의 내용을 전부 붙여넣습니다.
4. 저장(💾)합니다.

## 2단계 · 웹앱으로 배포하기

1. 편집기 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 아래 두 가지를 이렇게 고릅니다.
   - **다음 사용자로 실행** → `나`
   - **액세스 권한이 있는 사용자** → `모든 사용자`
4. **배포**를 누르면 권한 승인 창이 뜹니다.
   `고급` → `안전하지 않은 페이지로 이동` → `허용`
5. 나온 주소를 복사합니다. `https://script.google.com/macros/s/.../exec` 형태입니다.

> 액세스 권한을 `모든 사용자`로 두지 않으면 교육생 휴대폰에서 응답이 저장되지 않습니다.

## 3단계 · 주소 넣기

`config.js` 를 열어 방금 복사한 주소를 붙여넣습니다.

```js
var API_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

## 4단계 · 깃허브에 올리기

1. 깃허브에서 새 저장소를 만듭니다. (Public)
2. `index.html` `teacher.html` `config.js` 세 파일을 올립니다. (`Code.gs` 는 올려도 되고 안 올려도 됩니다)
3. 저장소 **Settings → Pages** 로 들어갑니다.
4. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/ (root)` 로 두고 저장합니다.
5. 1~2분 뒤 주소가 만들어집니다.

```
교육생용   https://아이디.github.io/저장소이름/
강사용     https://아이디.github.io/저장소이름/teacher.html
```

## 5단계 · 수업 전 점검

- [ ] 휴대폰으로 교육생 주소를 열어 항목을 고르고 보내 본다
- [ ] 노트북으로 강사 주소를 열어 방금 보낸 답이 뜨는지 확인한다
- [ ] 구글 시트에 줄이 쌓였는지 확인한다
- [ ] 강사 화면에서 **전체 지우기** 를 눌러 시험 데이터를 비운다 (비밀번호 `2026`)
- [ ] 교육생 주소를 단축주소·QR로 만들어 1회차 5번 슬라이드에 넣는다

## 바꾸고 싶을 때

**버튼 항목** — `index.html` 안의 `PRESET` 목록을 고칩니다.

```js
var PRESET = ['엑셀 취합','보고서 작성', ... ];
```

**질문 문구** — `index.html` 의 `<h1 class="q">` 부분을 고칩니다.

**지우기 비밀번호** — `Code.gs` 위쪽 `ADMIN_PIN` 값을 바꾸고 **다시 배포**합니다.
(배포 → 배포 관리 → 연필 → 버전 `새 버전` → 배포)

**Code.gs 를 고친 뒤에는 반드시 새 버전으로 다시 배포해야 반영됩니다.**

## 잘 안 될 때

**교육생 화면에서 "전송에 실패했습니다"**
`config.js` 주소가 비어 있거나, 웹앱 액세스 권한이 `모든 사용자`가 아닌 경우입니다.
주소 끝이 `/exec` 로 끝나는지도 확인하세요. `/dev` 로 끝나면 본인만 쓸 수 있습니다.

**강사 화면이 "연결 확인 중" 에서 멈춤**
브라우저 주소창에 `API_URL` 주소 뒤에 `?action=list` 를 붙여 직접 열어 보세요.
`{"ok":true,...}` 가 보이면 백엔드는 정상이니 `config.js` 오타를 확인하시면 됩니다.

**응답이 시트에 두 줄씩 쌓임**
교육생이 "하나 더 고르기"로 다시 보낸 경우입니다. 정상 동작입니다.
